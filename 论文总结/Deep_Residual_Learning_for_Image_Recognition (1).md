1.  什么是梯度爆炸、梯度消失？

梯度消失：在深层神经网络反向传播中，反向传播从输出层往输入层回传梯度，每一层都要乘上激活函数的导数。如果每一层导数都小于1，多层连续相乘之后，越靠近输入层，梯度变得越来越小，趋近于0。这种现象就会导致浅层（靠近输入）的权重几乎得不到更新，网络学不到东西，深层模型训不动

梯度爆炸：在深层神经网络反向传播中，每层梯度大于1，多层相乘后梯度指数级变大，数值巨大。这种现象会导致权重更新幅度巨大，参数震荡、NaN（数值溢出）。

CNN 更多遇到梯度消失；传统 RNN 长序列两种问题都会出现。

2.  什么是网络退化？产生网络退化的原因？

当神经网络层数不断增加时，训练集准确率先上升，达到饱和之后，继续加深层数，训练集准确率反而下降，测试集也跟着变差。原因是深度增加后，非线性层堆叠，优化空间变得复杂，SGD（Stochastic
Gradient
Descent）梯度下降很难找到好的参数解。模型有能力拟合，但优化器难以学到恒等映射，多余的几层会破坏前面已经学好的特征。

3.  什么是恒等映射？

恒等映射是一个极其简单的数学函数，它的作用就是：输入是什么，输出就原封不动地是什么。数学表达为：$f(x) = x$。例如给机器输入一个苹果，经过这个恒等映射的处理，吐出来的必须还是一个一模一样的苹果，不能变成香蕉，也不能烂掉一块。如果某一层网络要做到"恒等映射"，就意味着这层的权重 W 必须刚好等于单位矩阵（对角线为1，其余为0），偏置 b必须等于0。输出$Wx + b = 1 \ast x + 0 = x$。对SGD优化器来说，要把成千上万个随机初始化的数字（比如
0.372, -1.456, 0.891\...），通过一步步微调，精确地变成 1.000, 0.000,
0.000\... 这个极其精确的组合，是很困难的。

4.  什么是残差映射？

残差映射$F(x) = H(x) - x$是ResNet残差块中网络需要学习的映射，代表目标输出与输入之间的差值，残差块通过短路连接构造，当该部分网络不需要进行特征变换时，只需将残差映射学习为0即可实现恒等映射$H(x) = x$，以此解决深度网络的退化问题，同时也能够缓解梯度消失现象。

5.  什么是捷径连接？

    捷径连接（Shortcut
    Connection），指的是将网络某一层的输入特征图，不经过后续的非线性变换层，而是通过一条捷径直接跨层传递，并与该模块的输出进行逐元素相加（Element-wise
    Addition）的操作。数学上表示为$y = F(x,Wi) + x$，其中 $x$ 是输入，$F(x)$ 是堆叠的非线性层需要学习的残差映射。从优化角度看，捷径连接有效解决了深层网络的退化问题。 它使得优化器（如
    SGD）不再需要艰难地学习复杂的恒等映射（即让$f(x) = x$），而只需将多层权重的参数推向零（即$f(x)$趋近于
    0），即可保证深层网络至少不劣于浅层网络。同时，这条通道在反向传播中提供了一条"梯度高速公路"，确保深层的梯度信号能无损地回传到浅层，从而有效避免了梯度消失问题，使得训练数百层甚至上千层的深度网络成为可能。
